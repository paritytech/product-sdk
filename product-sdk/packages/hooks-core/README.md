# @parity/product-sdk-hooks-core

**Framework-agnostic runtime behind the React hooks and Vue composables.**

Host detection, chain clients, signers, transactions, contracts, chat,
statements, payments and cloud storage for Polkadot apps — the controller
layer that [`@parity/product-sdk-react`](https://www.npmjs.com/package/@parity/product-sdk-react)
and [`@parity/product-sdk-vue`](https://www.npmjs.com/package/@parity/product-sdk-vue)
bind to.

Most apps should install one of those instead; reach for this package
directly only to bind another framework or to use the controllers without
one.
