# Logging

All SDK packages emit structured logs through a shared logger. Every log entry carries a namespace, a level, a message, and an optional payload.

## Configure globally

`configure` sets the default level and handler for every logger created afterwards.

```ts
import { configure } from "@parity/product-sdk";

configure({
  level: "debug",
  handler: (entry) => {
    console.log(`[${entry.namespace}] ${entry.message}`, entry.data);
  },
});
```

## Create a scoped logger

```ts
import { createLogger } from "@parity/product-sdk";

const log = createLogger("my-app:checkout");
log.info("Started checkout", { cartId: "abc" });
log.error("Payment failed", { code: 402 });
```

## Levels

| Level | Use |
|-------|-----|
| `debug` | Verbose internal state — disabled in production |
| `info` | High-level flow events (connected, submitted, finalized) |
| `warn` | Recoverable anomalies (retry triggered, fallback used) |
| `error` | Unrecoverable failures surfaced to the caller |

Levels are ordered. Setting `level: 'warn'` silences `debug` and `info`.

## Namespaces

Each logger is created with a namespace string. The `namespaces` filter on `configure` restricts which namespaces receive the configured level; everything else falls back to `warn`.

```ts
configure({ level: "debug", namespaces: ["keys", "tx"] });
```

With the config above, `createLogger('keys')` and `createLogger('tx')` emit at debug; every other namespace only emits `warn` and `error`. Matching is exact — namespaces are not prefix-matched.

Omit the `namespaces` field (or pass `[]`) to apply the configured level globally.
