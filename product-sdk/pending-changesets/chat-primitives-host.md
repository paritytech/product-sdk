`@parity/product-sdk-host` serves Chat Extension v2. `getChatRooms()` (and `createChatRooms(client)`) gives a product's rooms: `createRoom`, `deleteRoom`, `setConfig`, `setMetadata`, `setPreview`, `setFooter`, `setFeatures`, `setCall`, `setContact`, `updateFeed` and `postMessage` (a host-store room's message, answered with the host's id) return a `Result`, a refusal such as `RateLimited` or `NotOwner` arriving as a `ChatRoomError` carrying the host's `failure`, and a feature the host does not serve (a method an older client lacks, or `contact_rooms`, which the core keeps for the person chat product) as a `FeatureUnavailableError` naming it. `features` says what the injected client carries, and `subscribeRoomEvents` fans one upstream room-event stream out to every listener. `serveChatQueries(handlers)` answers the host's queries (`messages`, `userAction`, `reactions`, `search`, `editHistory`, `openLink`) from promises: register it before the worker's first `await`; a handler throws `UnknownRoomError`, `UnknownMessageError`, `NotAvailableError` or `UserActionRejectedError` to refuse, and while the handlers are not ready every query is answered "unavailable", which the host asks again once. Also new: `getCallMedia()` (`start`, `signal`, `stop`, `CallMediaNotAllowedError`), `holdWorker(label)` and `OperationHold` (one host operation around overlapping work, ended 3 s after the last), `watchIdentity(read, onChange)`, `getFinalizedStorageReader(chain)` (storage at the newest finalized block without polkadot-api), `getTruApiSync()`, `NotificationManager.pushRoom(roomId, text)` and `roomDeeplink`, `ChatManager.setRoomFooter`, and the Chat Extension v2 types re-exported. A worker whose host puts the message port on the global object instead of `window` now finds it. `@parity/product-sdk-host/testing` gains `createFakeChatHost()`, a stand-in for the host's side of the chat: it keeps declarations and feed updates, applies the RFCs' room rules, bounds, rates and capability gating, drives every host query, and models call media, worker operations and notifications; pass it as `createFakeTruApiClient({ chatHost })`. Needs the `@parity/truapi` release that carries Chat Extension v2, `CallMedia` and `PersonChat`.
