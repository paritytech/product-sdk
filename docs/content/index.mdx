## Runtime

The SDK runs inside a Nova Wallet host — Polkadot Desktop or Polkadot Mobile. `createApp` opens host storage and wires the Host signer provider. For local development, the [`@parity/host-api-test-sdk`](https://github.com/paritytech/host-api-test-sdk) provides a browser-based test host the SDK connects to identically.

See [Runtime Environment](/getting-started/container-vs-standalone).
