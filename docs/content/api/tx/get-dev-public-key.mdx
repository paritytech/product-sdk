# `getDevPublicKey()`

Get the public key bytes for a dev account.

Useful for address derivation or identity checks in tests without
needing the full signer.

```ts
getDevPublicKey(name: DevAccountName): Uint8Array
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `name` | `DevAccountName` | Dev account name. |

## Returns

`Uint8Array` — 32-byte Sr25519 public key.
