# configure

Set the global log level, namespace filter, and output handler. Applies to every `Logger` created before or after the call.

## Signature

```ts
function configure(config: LoggerConfig): void
```

## Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `config.level` | `LogLevel` | `'warn'` | Minimum level to emit. One of `'error' \| 'warn' \| 'info' \| 'debug'`. |
| `config.namespaces` | `string[]` | `undefined` | If set, only listed namespaces receive `level`; all others stay at `'warn'`. Empty array applies `level` globally. |
| `config.handler` | `LogHandler` | `undefined` | Custom output handler. Replaces the default `console.*` output. |

### `LogHandler`

```ts
type LogHandler = (entry: LogEntry) => void;
```

## Returns

`void`

## Examples

### Raise the level globally

```ts
import { configure } from "@parity/product-sdk";

configure({ level: "debug" });
```

### Restrict verbosity to specific namespaces

```ts
configure({
  level: "debug",
  namespaces: ["keys", "tx"],
});
```

Only `keys` and `tx` emit at `debug`. Every other namespace stays at `warn`.

### Pipe to a custom sink

```ts
configure({
  level: "info",
  handler: (entry) => {
    myTelemetry.record({
      level: entry.level,
      namespace: entry.namespace,
      msg: entry.message,
      data: entry.data,
      ts: entry.timestamp,
    });
  },
});
```

## Notes

- `configure` is idempotent. Each call replaces the fields you pass; omitted fields keep their previous value.
- Namespace matching is exact. Namespaces are opaque strings, not colon-separated hierarchies.
- The default handler prefixes each line with `[namespace]` and calls `console.error`, `console.warn`, `console.info`, or `console.debug` based on level.
