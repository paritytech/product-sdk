# `aesGcmDecrypt()`

Decrypt binary data with AES-256-GCM.

```ts
aesGcmDecrypt(ciphertext: Uint8Array, key: Uint8Array, nonce: Uint8Array): Uint8Array
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `ciphertext` | `Uint8Array` | Data to decrypt (includes the 16-byte GCM auth tag). |
| `key` | `Uint8Array` | 32-byte AES-256 key (must match the encryption key). |
| `nonce` | `Uint8Array` | 12-byte nonce used during encryption. |

## Returns

`Uint8Array` — The decrypted plaintext as a `Uint8Array`.

## Throws

- If `key` is not 32 bytes, or if decryption/authentication fails.
