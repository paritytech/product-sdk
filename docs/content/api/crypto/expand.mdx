# `expand()`

HKDF-expand from the spec. The most important part. `HKDF-Expand(PRK, info, L) -> OKM`

```ts
expand(hash: (msg: Input) => Uint8Array, prk: Input, info?: Input, length?: number): Uint8Array
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `hash` | `(msg: Input) => Uint8Array` | hash function that would be used (e.g. sha256) |
| `prk` | `Input` | a pseudorandom key of at least HashLen octets (usually, the output from the extract step) |
| `info` _(optional)_ | `Input` | optional context and application specific information (can be a zero-length string) |
| `length` _(optional)_ | `number` | length of output keying material in bytes |

## Returns

`Uint8Array`
