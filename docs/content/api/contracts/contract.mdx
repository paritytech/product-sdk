# `type Contract`

A typed contract handle where each ABI method exposes `.query()` and `.tx()`.

Both accept the method's positional arguments followed by an optional
options object as the last argument.

```ts
type Contract = { [K in keyof C["methods"]]: { query: (...args: [...C["methods"][K]["args"], unknown]) => Promise<QueryResult<C["methods"][K]["response"]>>; tx: (...args: [...C["methods"][K]["args"], unknown]) => Promise<TxResult> } }
```
