# `createContractFromClient()`

Create a contract handle from a raw `PolkadotClient`, address, and ABI.

Convenience wrapper that creates the InkSdk internally via dynamic import.
For size-sensitive apps, use `createContract` with a pre-created `InkSdk`.

```ts
createContractFromClient(client: PolkadotClient, address: HexString, abi: AbiEntry[], options?: ContractOptions): Promise<Contract<ContractDef>>
```
