# `type BatchUploadResult`

Result for one item in a batch upload.

Discriminated on `kind` (upload path) and `success` (outcome).
Use `result.success` to check for errors, then `result.kind` to access
path-specific fields like `blockHash` or `preimageKey`.

```ts
type BatchUploadResult = BatchUploadResultBase & { blockHash: string; kind: "transaction"; success: true } | BatchUploadResultBase & { kind: "preimage"; preimageKey: string; success: true } | BatchUploadResultBase & { error: string; kind: "transaction" | "preimage"; success: false }
```
