# `upload()`

Upload data to the Bulletin Chain.

When a signer is provided, submits a `TransactionStorage.store` transaction
directly. When omitted, uses the host preimage API — the host signs and
submits automatically.

Computes the CIDv1 (blake2b-256, raw codec) locally.

```ts
upload(api: BulletinApi, data: Uint8Array, signer?: PolkadotSigner, options?: UploadOptions): Promise<UploadResult>
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `api` | `BulletinApi` | Typed Bulletin Chain API. |
| `data` | `Uint8Array` | Raw bytes to store. |
| `signer` _(optional)_ | `PolkadotSigner` | Optional signer. When omitted, uses host preimage API. |
| `options` _(optional)_ | `UploadOptions` | Upload options (gateway, timeout, waitFor, status callback). |

## Returns

`Promise<UploadResult>` — Upload result with CID and either blockHash or preimageKey.
