# `resolveUploadStrategy()`

Determine the upload strategy for the Bulletin Chain.

Resolution order:
1. If an explicit signer is provided, use it directly.
2. Otherwise, use the host preimage API (the SDK is designed to run inside a container).

```ts
resolveUploadStrategy(explicitSigner?: PolkadotSigner): Promise<UploadStrategy>
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `explicitSigner` _(optional)_ | `PolkadotSigner` | Optional signer provided by the caller. When present, skips host auto-detection entirely. |

## Returns

`Promise<UploadStrategy>` — The resolved upload strategy.

## Throws

- If no signer is provided and the host preimage API is unavailable.
